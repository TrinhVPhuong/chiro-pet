# Project Brief: Chiro-Pet

## Core Foundation
**Chiro-Pet** is a Desktop Companion App that runs on Windows, featuring an interactive 3D virtual character (VRM) that lives directly on the user's desktop. 

## Project Scope & Nature
- **Overlay Application:** Operates as a transparent, topmost overlay that does not obstruct the user's workflow (click-through support).
- **Offline-First Privacy:** All core logic, state management, memory, and model rendering run locally. Internet connection is only required for complex AI conversations via OpenAI-compatible APIs. There is no backend server or cloud synchronization, ensuring complete data privacy.

## Four Pillars of Experience
1. **Presence:** The character feels alive and continuous without being intrusive.
2. **Context:** The system recognizes user context (coding, gaming, in a meeting, or idle).
3. **Proactivity:** The character initiates conversation or actions at appropriate times and places.
4. **Trust:** Data is entirely private and controlled by the user.

## Core Objectives
To build a highly optimized, cross-platform capable (starting with Windows), interactive virtual companion that evolves over time, reacting to user inputs, screen context, and maintaining a dynamic relationship with the user.
